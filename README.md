Mansion Adventure Game

A Python-based text adventure game where players explore a mansion, navigate connected rooms, and interact with items and missions.

Features

- **Room Navigation:** Move between connected rooms throughout the mansion.
- **Object-Oriented Programming:** Uses classes and objects to organize game components.
- **Item Management:** Explore and manage items stored in the game.
- **Mission System:** Complete missions using a queue-based system.
- **Movement History:** Uses a stack to track previous movements.
- **Sorting and Searching:** Implements algorithms to organize and search through a large item catalog.
- **Exception Handling:** Uses custom exceptions to handle game-related errors.

Technologies Used

- Python
- Object-Oriented Programming (OOP)
- Data Structures (Stacks and Queues)
- Searching and Sorting Algorithms
- Git and GitHub

How to Run

1. Clone this repository:
   git clone https://github.com/gurfatehsuper-cyber/Mansion-Adventure-Game.git
   
2. Open the project folder.

3. Run the game:
   python adventure_game.py
